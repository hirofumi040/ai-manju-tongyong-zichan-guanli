# 多视角研究过程

## 推进链路

1. 将场景从“风格相近的背景”重新定义为可重复观察的空间。
2. 拆为拓扑、固定物件、视觉识别、观察视角四层；把七类内容组织进空间/视觉/机位描述。
3. 用户选择同时建立六联图版式与生成写法。版式为16:9、上排定位图与主视觉、下排四个不同观察任务、无文字无边框满幅。
4. 初稿建议先生成整张六联图；后续改为先定布局和主视觉，再逐张生成左斜、右斜、反向、局部，检查后合成。
5. 提出固定空间锚点与视觉条件，仅改变观察点、朝向、景别及遮挡；空间不稳定时增加几何参考，而非无限堆词。

## 研究稿的机位设想

| 任务 | 原设想 | 需复核 |
|---|---|---|
| 左斜 | 西南角朝东北 | 可见墙面由视锥推导，原稿要求看西窗不一定成立 |
| 右斜 | 东南角朝西北 | 东侧入口是否可见不能只靠文字保证 |
| 反向 | 北侧朝南 | 原稿南侧入口与东墙入口冲突 |
| 局部 | 近书桌观察文房器物 | 不能替代整体空间覆盖 |

这些是保留的草案，不是已通过几何验证的标准机位表。确认空间时先统一入口、窗和墙向，再修订对应机位。

## 三组案例不可混用

- 现代公寓文字案例：长方形、南窗北电视、东餐厅西入口。
- 原书房研究稿：北墙画与书柜、西窗、东侧入口/边柜，同时夹有南入口描述。
- 42页教学示例：北墙书柜、南入口、东窗、桌居中。

三者属于不同例子或不同草案，不能共享一个未经核准的SCN编号。总办现代会客空间/书房是本轮补充图，不是这些文字的生成验证图。
